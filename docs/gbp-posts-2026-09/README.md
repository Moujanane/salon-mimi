# Posts Google Business Profile — septembre 2026

3 posts prêts à publier sur la fiche Google (Salon Mimi, Place Jamaa El Fna).

## Comment publier

1. Google Maps ou google.com/business → fiche Salon Mimi
2. Bouton **Ajouter une actualité** (ou **Promouvoir** → **Ajouter une nouveauté**)
3. Type : **Nouveauté** (pas « Offre », pas « Événement »)
4. Coller le texte du post, ajouter la photo indiquée
5. Bouton d'action : **Réserver** → `https://mimi-coiffure.com/fr/reservation`
6. Publier

Rythme : **1 post par semaine**. Ne pas publier les 3 le même jour.

Règles GBP respectées ici : photos sans texte incrusté, sans montage, prises au
salon. Google Business n'est pas Instagram.
